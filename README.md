# Student Database Management System

## Project Description
This project is developed using Python, Tkinter, and SQLite.
It helps users manage student records through a graphical interface.

## Features
- Add student records
- View student records
- Search student records
- Update student records
- Delete student records

## Technologies Used
- Python
- Tkinter
- SQLite

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python main.py
